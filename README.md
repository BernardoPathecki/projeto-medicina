# 🌸 Minha Saúde Feminina

O projeto **Minha Saúde Feminina** foi desenvolvido pelos cursos de Sistemas de Informação e Medicina da UNIFEBE com o objetivo de criar uma ferramenta digital voltada à saúde da mulher.

O aplicativo busca oferecer informações confiáveis e acessíveis, além de auxiliar no acompanhamento do ciclo menstrual, registro de sintomas e incentivo ao autocuidado.

---

## 🚀 Funcionalidades

- Cadastro e login de usuários;
- Diferenciação entre usuários comuns e administradores;
- Cadastro de conteúdos pelo administrador;
- Visualização de conteúdos educativos;
- Registro de sintomas;
- Acompanhamento do ciclo menstrual.

---

## 📋 Requisitos Não Funcionais

- Interface simples e de fácil uso;
- Segurança dos dados dos usuários;
- Compatibilidade com dispositivos móveis;
- Informações claras e compreensíveis;
- Bom desempenho nas consultas e registros.

---

## 🛠 Tecnologias Utilizadas

### Front-end
- React Native
- Expo
- TypeScript

### Banco de Dados
- Supabase
- PostgreSQL

---

## 🗂 Modelagem do Banco de Dados

O sistema utiliza um banco de dados relacional baseado em PostgreSQL, garantindo organização, integridade e facilidade na consulta das informações.

## 📱 Objetivo do Projeto

O projeto tem como objetivo promover maior acesso à informação sobre saúde feminina, incentivando o autocuidado, a prevenção e o acompanhamento contínuo da saúde da mulher através da tecnologia.
